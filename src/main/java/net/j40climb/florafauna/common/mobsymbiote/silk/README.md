# Spider silk habitat

Craft one Mob Symbiote from a red mushroom, a brown mushroom and wheat seeds in any arrangement. Right-click an ordinary spider with the symbiote to bond it. A bonded spider stays in the world when you leave. Bring it to the habitat by luring it or using the mod’s mob transport.

1. Put two fence posts in a straight row with **one to three empty blocks** between them. Start with a flat floor and chest-high posts.
2. Give one end shelter. A full plank block directly above either post is enough. Leave a walkable spot beside that post and enough clear space inside the gap for a full-size spider.
3. Keep the spider close. It looks for nearby posts, moves into the gap, and spins a white line. It hangs upside down for about five seconds before moving back toward the sheltered post.
4. Right-click any part of the line with shears to collect **one string for the whole span**. Cut it early and the spider drops off with a little puff and a squish. A dispenser facing any silk segment can use shears too. A hopper under the cut collects the drop.

The spider can spin again one minute after making a line. Leaving the old line in place keeps that gap occupied. Removing a post or breaking the line without shearing clears the loose silk. Spinning respects the mob griefing setting and only uses air blocks. Cave spiders and unbonded spiders keep their usual behavior.

The headless tests cover shearing a hanging spider, harvesting an abandoned line with a powered dispenser, and protecting existing blocks and wild spiders. Run the `spider` client scenario on a copy of a 26.1 save to check bonding, rendering and harvesting.
