Follow the shared localization and verification instructions. [AGENTS.md](../../AGENTS.md)

1. Search the requested feature for player-facing text in screen titles, buttons, tooltips, item names and messages. Check calls to `Component.literal`, `Component.translatable` and `GuiGraphicsExtractor.text`. Classify each use by who sees it. Logs, registry IDs and player-provided names can contain literal text.
2. Resolve mod-owned translation keys against `src/main/resources/assets/florafauna/lang/en_us.json`. For dynamic keys, check each value the feature can produce. For a missing entry, use the feature's existing key pattern, preserve formatting arguments, and check that the English JSON still parses. [English translations](../../src/main/resources/assets/florafauna/lang/en_us.json) · [Tool config screen](../../src/main/java/net/j40climb/florafauna/common/item/abilities/menu/ToolConfigScreen.java)
3. When reviewing, identify the source location, missing key or hardcoded phrase, and proposed wording. When implementing a correction, update the Java call and resource together as applicable, then verify that the player sees the expected text in context.
