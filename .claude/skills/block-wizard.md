Use the shared instructions for checkout ownership, testing and integration. [AGENTS.md](../../AGENTS.md)

1. Identify the needed block state, player interactions and drops. Keep related behavior in `common/block/<feature>/`. For stored data follow Husk or Mob Barrier. For a menu with inventory follow the Containment Chamber. [Husk](../../src/main/java/net/j40climb/florafauna/common/block/husk) · [Mob Barrier](../../src/main/java/net/j40climb/florafauna/common/block/mobbarrier) · [Containment Chamber](../../src/main/java/net/j40climb/florafauna/common/block/containmentchamber)
2. Register the block and any block entity or menu in `FloraFaunaRegistry`. Its `registerBlock` helper creates a standard block item. Follow the Mob Barrier pattern for a custom item and the Tier 1 Pod for a block without an inventory item. For a wood family, follow `WoodType` and `WoodBlockRegistration`. [Registry](../../src/main/java/net/j40climb/florafauna/setup/FloraFaunaRegistry.java) · [Wood registration](../../src/main/java/net/j40climb/florafauna/common/block/wood)
3. Add the applicable creative-tab entry in `FloraFaunaSetup`. Register a menu screen through `ClientSetup.registerScreens` when the block needs one. [Common setup](../../src/main/java/net/j40climb/florafauna/setup/FloraFaunaSetup.java) · [Client setup](../../src/main/java/net/j40climb/florafauna/setup/ClientSetup.java)
4. Update models, tool tags, loot and recipes as the feature requires. For custom blockstates, verify the variant keys exist on the block and provide the corresponding placed-block and inventory models. Check whether the block already handles drops before choosing a loot table. Add textures under `textures/block/` and an English `block.florafauna.<id>` entry. [Data providers](../../src/main/java/net/j40climb/florafauna/common/datagen) · [Assets](../../src/main/resources/assets/florafauna) · [Datagen runner](datagen-runner.md)
5. Generate resources, build and test the observable behavior. For blocks with persistent contents, test a reload and an actual transfer or break. Report the feature's checks and any missing textures.
